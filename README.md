# Ruby Complete Pack

A practical Ruby learning pack for beginners to intermediate developers. It covers Ruby syntax, methods, collections, object-oriented programming, blocks, files, testing, and small CLI projects.

## Requirements

- Ruby 3.2+ recommended
- No external dependencies required for the basics

## Run examples

```bash
ruby 01_basics/hello.rb
ruby 08_projects/calculator.rb
```

## Contents

- `01_basics/`: variables, conditionals, operators
- `02_collections/`: arrays, hashes, ranges
- `03_methods_blocks/`: methods, blocks, lambdas
- `04_oop/`: classes, inheritance, modules, encapsulation
- `05_exceptions_files/`: exceptions, files, JSON
- `06_enumerables/`: each, map, select, reduce
- `07_testing/`: Minitest basics
- `08_projects/`: calculator, todo list, and text analyzer

## Notes

Most examples are standalone scripts. The projects are small CLI programs intended for local learning.
